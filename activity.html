5. HTML DOM

The HTML Document Object Model (DOM) represents a web page as a tree of elements. Each HTML element becomes a node that can have parent and child relationships.

DOM Tree

                 html
                    └── body
                        └── main
                            └── section#html-dom
                                ├── h2
                                ├── p
                                ├── h3#dom-heading
                                └── div#dom-container
                                    └── article#dom-article
                                        ├── h4#dom-subheading
                                        ├── p
                                        └── ul#dom-list
                                            ├── li
                                            ├── li
                                            └── li
